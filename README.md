# dsh-canvas-workspace

让你的 dsh 更加好用。

一个实验性的 DeepSeek Harness 画布插件。右下角使用 DSH 原生输入框；用户消息留在可滚动的右侧栏，Agent 回复显示在可平移、缩放的画布中。回复可以用顶部拖柄单独移动，新回复从上一条回复的实际位置下方开始。

## 功能

会话标题下方的原生“对话 / 轨迹”视图栏现可直接选择 **画布**，空间不足时由 DSH 原生“更多会话视图”菜单管理。此入口绑定当前会话并复用原有输入框，切换视图保留草稿、历史和卡片位置，不停止原生会话执行。画布模式隐藏宿主常驻左栏，由左上角小菜单开合浮层侧栏；返回对话后恢复原布局和侧栏宽度偏好。

- 触屏可直接在回复正文或空白画布上双指缩放、平移，以两指中心保持锚点；抬起一指后可继续平移。单指正文选字、链接、按钮、输入框和可滚动内容保持原生操作。若任一触点始于控件、实际可滚动区域或 IUI 自有交互区，该次手势不接管画布。
- 同一 DSH 会话中的原生发送、停止、图片与文件附件、流式回复和历史恢复。
- Markdown 与受限 IUI 混排；无效片段保留原文，其余内容继续显示。IUI 图片仅解析明确的 URL 或工作区文件路径。
- 原生 `ask_user_question` 的选项和自定义回答也会出现在右侧消息列表，与对应 Agent 回复关联；工具错误或未回答的问题不会伪装成用户消息。
- DSH 返回思考字段时，生成中显示最新内容，完成后可按需展开查看。
- 右侧已发送消息按 DSH 用户消息样式呈现文字、图片和文件；图片支持预览，文字支持选择与复制。Steer 消息保留各自内容，并与同一回复成组关联。
- 双向悬停高亮、点击用户消息定位回复、三条左右高度的消息栏内滚、柔和背景和减少动态效果支持。
- 画布侧边栏复用 DSH 侧边栏的组件样式与图标：新会话、插件/自动化任务/更多、工作区搜索、视图切换、新增工作区和分组会话树。会话数据来自宿主公共控制器，遵循默认列表对空会话、子 Agent、归档、置顶与标题的规则，分组内默认按更新时间排序。浮层的折叠/搜索/视图选项独立于原生侧栏的本地偏好（宿主未公开该偏好接口）。它以浮层覆盖在画布上，不占用画布宽度；通过顶部原生会话页签切换画布与对话。

原生画布页签左上角工具栏 → **自动排布**（原“画布菜单 → 更多 → 按视口自动排布”入口仍可用），会按当前缩放将画布完整可视宽度换算为排布宽度（左右各留 24px），整理全部未钉住的回复并避开已钉住卡片。消息列表和输入框不再占用排布宽度，允许覆盖下方卡片。宽度足够时排列为多列，放不下时向下延伸，不缩小文字、不改变镜头。图片加载、思考展开或流式内容真实增高并侵入其他卡片间距时，只向下调整必要的碰撞链；同高度更新、内容缩短和普通尺寸通知不会重排。新增回复只计算自己的落点，不移动已有卡片。首次加载、会话恢复和缩放本身不会触发整体排布；手动移动不等于钉住，下次主动排布仍会参与；回复顶部的纯图标按钮控制固定状态：未固定为划线图钉，固定后为高亮图钉，已钉住卡片不可拖动并作为布局障碍。钉住状态按会话保存。旧存档不会被自动视为钉住，加载时保留原坐标，主动排布时才应用新语义。布局随会话保存，平移、缩放和窗口变化不会触发重新整理；需要适应新视口时再次点击即可。新回复延续前一回复下方并参与避碰。

回复卡片右上角、固定按钮旁的定位图标可将右侧消息列表滚动到对应输入，并转移键盘焦点；关联使用宿主消息/回合 ID，同文消息不会混淆。消息元数据稍后到达或列表恢复显示时会继续待完成定位。时间与复制按钮放到气泡左侧原有空白处，不再为隐藏的操作栏保留底部高度。列表底部不再叠加留白，原生输入区上方保留约 4px 间距，并随输入框增高收缩可用列表高度。主动排布时卡片以约 320ms 平滑移动到目标位置；再次点击会从当前画面继续，拖动、镜头操作和减少动态效果偏好会取消动画。

“更多 → 画布 IUI 渲染”默认开启，只切换已有 IUI 内容的显示，不会给模型注入生成协议。希望 Agent 主动生成 IUI 时，需要另行配置 `open-intelligent-ui` 提示插件或明确提供协议；显示已有 IUI 不需要额外安装该插件。

Canvas 只在显示层处理历史和布局，不修改已有 DSH 会话事件。图片通过宿主授权的资源加载接口读取，不从展示文字推测附件。普通发送由原生输入框负责；测试不发送真实模型请求。

## DSH 0.2.2 边界兼容

修复新版宿主新增主面板包装层后，画布左侧仍保留原生侧栏轨道而裁切内容的问题。侧栏展开或收起进入画布都使用完整主区域，退出后恢复原来的侧栏状态、宽度和未发送草稿；不通过取消全局 `overflow` 掩盖边界。

`node tests/frame-bounds.browser.mjs` 覆盖新旧主区域结构、不同侧栏/右栏宽度，并验证旧选择器会复现空白边界。`node tests/frame-bounds.host.mjs` 使用隔离的真实宿主，覆盖展开、收起、再展开进入与退出画布。可通过 `DSH_TEST_NODE`、`DSH_TEST_CLI`、`CHROMIUM_PATH` 指定测试运行时，不读取个人会话或调用模型。

## 开发与检查

要求 Node.js `^22.19.0 || >=24`。当前开发依赖固定为 DSH `0.2.2-rc.1` 与 Cordis `4.1.0`；声明支持 `0.2.0-rc.2`、`0.2.1-rc.2`、`0.2.1-rc.3` 与 `0.2.2-rc.1`，其它版本需单独验证。源码修复版已适配 rc.1 新增的原生图片拖放接口，文件传输仍由宿主负责；旧宿主没有此服务时不阻塞画布加载。注意：该声明针对当前源码构建，不代表旧的 npm `0.2.4-experimental.2` 已包含这些适配。

```bash
npm ci
npm run typecheck
npm test
npm run format:check
npm run test:media
npm run test:rail
npm run test:touch
node tests/viewport-layout.browser.mjs
node tests/layout-stability.browser.mjs
npm run build
```

桌面版的 `npm run test:host` 使用已安装的 macOS DSH、全新隔离 profile 和合成历史，覆盖原生画布页签与侧栏恢复。首次运行可用 `npm install --prefix .research/pnpm --ignore-scripts pnpm@11.28.5` 准备局部测试工具；不会改全局 pnpm 或个人 DSH 配置。

`npm run test:touch` 增加两个画布入口的持续单指拖动回归（每轮 30 个采样、连续 3 轮，并检查松手后无回跳），避免只发送一次 move 漏掉触摸事件可取消性变化。相机移动不再重复渲染未变化的历史 Markdown/IUI 内容；12 条历史回复、60 次移动的 DOM 回归从 720 次正文渲染降为仅初始 12 次。

`npm run test:touch` 使用 Chromium CDP 的真实多触点输入，覆盖横屏、竖屏、198×242 小屏及桌面视口，两个画布入口、双指中心缩放/平移、触点增减与替换、原生滚动/控件边界及取消恢复。浏览器已接管的滚动不会再转换为画布手势。本地自动化不等于 iOS Safari 真机验证；本次未做 iPhone、iPad 或 Apple Watch 真机测试。插件只调整页面内画布，不能修改或隐藏 Safari 的系统地址栏、标签栏与工具栏。

`npm run dev` 启动独立 MOCK 演示。浏览器测试使用本地 Vite 页面，不连接用户当前运行中的 DSH；宿主测试脚本另需隔离的官方 DSH 测试环境。`npm run build` 生成宿主插件 `dist/` 与本地演示 `site/`。仓库包含可直接由现有 DSH 插件链接读取的 `dist/`，`site/` 和测试截图、日志不提交。

## DSH 安装与兼容验证

可直接安装实验版：

```bash
dsh plugin --profile desktop add dsh-canvas-workspace@0.2.4-experimental.2
```

也可以使用 `dsh-canvas-workspace@experimental` 获取实验版标签指向的版本。npm 包包含构建后的 `dist/`，安装后重启对应的 DSH profile，无需下载源码或手动构建。

在插件仓库目录执行：

```bash
npm ci
npm run build
dsh plugin --profile desktop add "$PWD"
```

安装后打开已有会话，在会话标题下方选择 **画布**（空间不足时在“更多会话视图”中选择）。本地目录通过链接接入，请保留该目录。

rc.3 的隔离宿主检查可复现为：

```bash
npm install --prefix .research/runtime-021rc3 --save-exact @deepseek-ai/dsh@0.2.1-rc.3
DSH_TEST_RUNTIME=.research/runtime-021rc3 npm run test:host:http
```

宿主检查使用独立 `.host-test/` 配置，不继承个人账号和模型凭据，不设置版本豁免，也不发送模型请求。该检查验证官方安装器、启动图和插件资源；实际画布显示还需在 DSH 中打开验证。

2026-11-04 已使用 rc.3 官方依赖通过类型检查、161 项单元/DOM 测试、格式检查和完整构建；另用桌面版自带的 rc.3 CLI，在空白隔离 Web 配置中验证无豁免安装、启动图与构建文件一致，并确认画布模式下侧边栏以浮层呈现、画布保持全宽，搜索、视图切换、更多菜单和退出画布均可用。以上验证均未发送模型请求。

## 源码与边界

- `src/client.tsx`：DSH 公共扩展点、原生输入框和会话资源接入。
- `src/ui/`：画布、消息栏、侧边栏、回复、图片预览和交互。
- `src/adapters/`：DSH 事件投影与离线 MOCK。
- `vendor/open-intelligent-ui/`：按 MIT 许可保留的受限 IUI 源码；本地差异见其 `CANVAS_PROVENANCE.md`。
- `tests/`：单元、DOM 和隔离浏览器回归。

原生完整用户消息行没有独立公开接口，因此右侧消息区参照 DSH 的 MIT 源码结构与主题 token 实现，并复用公开文件图标、剪贴板、Tooltip、资源加载和灯箱。Canvas 尚未接入原生消息分支操作，也没有原生账户头像接口。项目许可见 [LICENSE](LICENSE)，第三方归属与许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
